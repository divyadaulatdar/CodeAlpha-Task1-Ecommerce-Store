# CodeAlpha Task 1 - Simple E-commerce Store

A simple e-commerce store website developed as part of the CodeAlpha Full Stack Development Internship.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

## Features

- Responsive e-commerce website
- Product listing
- Product details page
- Shopping cart functionality
- Product data management
- Backend server using Node.js and Express.js
- Clean and user-friendly interface

## Project Structure

CodeAlpha-Task1-Ecommerce-Store/
- data/
  - products.json
- public/
  - index.html
  - product.html
  - script.js
  - style.css
- package.json
- server.js
- README.md

## How to Run

1. Install Node.js.
2. Clone this repository.
3. Open the project folder in terminal.
4. Run: npm install
5. Start the server: node server.js
6. Open the website in your browser.
